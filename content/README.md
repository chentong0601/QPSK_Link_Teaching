# content/ —— 真实内容素材目录

> 用途：存放**待通过 QPSK 链路实际传输的真实内容**（文字 / 图片 / 视频 / 语音）。
> 目的：把实验从"传输合成测试数据"升级为"传输真实内容"，提升报告的说服力。
>
> 建立日期：2026-09-15

---

## 目录结构

```
content/
├── README.md      本说明
├── text/          文字素材（.txt / .md）
├── image/         图片素材（.jpg / .png / .bmp）
├── video/         视频素材（.mp4 / .avi）
└── audio/         语音素材（.wav / .mp3）
```

---

## 放什么

| 目录 | 建议内容 | 说明 |
|------|---------|------|
| `text/` | 一段有意义的中文/英文文本 | 如一段课程说明、一首诗、一段致辞；**不要放纯随机字符**——真实文本才能体现"内容语义" |
| `image/` | 一张有语义的图片 | 如校徽、课程相关示意图、生活照；**避免大面积纯色**（JPEG 压缩率过高会失去代表性） |
| `video/` | 一段短视频 | 有运动的真实画面；**避免静止画面**（静止视频帧间几乎相同，测不出运动补偿差异） |
| `audio/` | 一段语音 | 如一段朗读、一段口述说明；**推荐有人声**（语音比音乐更能体现可懂度） |

> 若老师提供了统一素材，直接把老师给的原始文件放进来即可，无需自行转换格式。

## 格式与大小建议

链路可用净荷约 **392 kbps（≈ 49 KB/s）**，这是所有素材处理的硬约束。原始素材可以大一些，我会自动预处理（缩放 / 重采样 / 压缩）成链路能传的规格，但**过大会显著增加处理与实验时间**。

| 类型 | 推荐规格 | 上限建议 | 交付形式 |
|------|---------|---------|---------|
| 文字 | 任意长度 | ≤ 100 KB | 逐字节比对，要求 100% 正确 |
| 图片 | ≤ 1920×1080 | ≤ 5 MB | 缩放至 320×240 / 176×144，JPEG 压缩后传输 |
| 视频 | ≤ 10 秒 | ≤ 50 MB | 抽帧 → 缩放 → JPEG 序列 → 分片传输 |
| 语音 | 单声道 | ≤ 3 分钟 | 重采样至 8 / 16 kHz，PCM 或 ADPCM 后分片传输 |

**参考吞吐能力**（实测标定值）：

| 配置 | 每帧字节 | 可达帧率 |
|------|---------|---------|
| 320×240 JPEG Q50（运动内容） | ≈ 7.4 KB | ≈ 6 fps |
| 176×144 JPEG Q50（运动内容） | ≈ 1.4 KB | ≈ 17 fps |
| 160×120 JPEG Q50 | ≈ 1.2 KB | ≈ 26 fps |

⇒ 举例：10 秒的 320×240 视频，传输约需 **20~30 秒**；3 分钟 8 kHz 语音，传输约 **30 秒**（语音码率远低于视频）。

## 命名建议

用**能说明内容**的文件名，会直接进入报告图题与说明：

- ✅ `校徽.jpg`、`课程致辞.mp3`、`实验室行走.mp4`、`实验说明.txt`
- ❌ `1.jpg`、`test.mp4`、`a.wav`

若同一类放多个文件，请用数字前缀标明优先顺序：`01_校徽.jpg`、`02_实验台.jpg`

## 我会用这些素材做的实验

| 实验编号 | 名称 | 素材 | 核心指标 |
|---------|------|------|---------|
| E4-TXT | 文字端到端传输 | `text/` | 逐字节正确率（要求 100%） |
| E4-IMG | 真实图片传输 | `image/` | PSNR、SSIM、传输耗时 |
| E4-VID | 真实视频传输 | `video/` | 帧还原率、平均 PSNR、等效帧率 |
| **E4-AUD** | **语音传输（新增领域）** | `audio/` | 波形相关系数、MOS 主观评分、可懂度 |

> E4-AUD 是本项目此前**完全没有涉及**的内容类型，将成为报告的一节独立实验。
