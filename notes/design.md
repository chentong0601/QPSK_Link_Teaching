# 设计文档 — 基于 ADALM-Pluto 的低空无人机遥测 QPSK 链路

> 版本: v1.0 (2026-09-09) | 状态: 设计定稿, 待实施
> 关联工程: `QPSK_Link_Teaching`（本工程，README.md 见目录根）

## 1. 项目概述

### 1.1 背景与动机
无线通信是低空无人机系统的核心使能技术——遥控指令下行、遥测数据上行、图传等都依赖可靠的数字链路。本课程项目以 **ADALM-Pluto（PlutoSDR）** 为硬件平台，从零实现一条 **QPSK 调制的无线遥测链路**，覆盖"数据打包 → 调制 → 真实空口发射 → 接收同步 → 解调还原 → 质量测量"的完整通信系统环节。

### 1.2 设计目标
1. **功能目标**：实现一条真实空口可用的 QPSK 数据链路，支持三种内容传输（文字消息 / 遥测数据帧 / 灰度图像渐进传输）。
2. **教学目标**：通过亲手搭建，深入理解数字通信接收机最核心的**同步问题**——帧同步（波形从哪开始）与载波同步（星座为何旋转）。
3. **课程目标**：交付包含理论推导、实测数据、现场演示的系统与报告。

### 1.3 与既有工作的关系
本工程建立在先前完成的仿真基础上（工程 `PlutoSDR_Wireless_Transceiver`）：
- **已完成并复用**：QPSK 基带收发函数库（`tx_baseband.m`/`rx_baseband.m`）、RRC 成形与匹配滤波设计、Pluto 单音硬件链路验证。
- **本工程新增**：帧结构设计、接收端同步算法链（帧检测 + 频偏估计/补偿）、多种内容源封装、实测数据采集与演示界面。

## 2. 系统架构

### 2.1 五层数据流架构

```
┌─────────────────────────────────────────────────────────────┐
│ L5 应用层: 内容源（可切换）                                    │
│   文字消息 │ 遥测数据帧 │ 灰度图像渐进                          │
│   帧号 + CRC → 丢帧统计                                        │
├─────────────────────────────────────────────────────────────┤
│ L4 链路层: 组帧                                               │
│   前导(32符号) | 帧头(类型/长度/帧号) | payload                 │
├─────────────────────────────────────────────────────────────┤
│ L3 物理层 TX: QPSK调制 → 上采样 → RRC成形 → 归一化 → sdrtx      │
├─────────────────────────────────────────────────────────────┤
│ L2 物理层 RX: sdrrx → 匹配滤波 → 帧检测 → 频偏补偿 → 判决       │
├─────────────────────────────────────────────────────────────┤
│ L1 测量层: 实测BER/EVM/丢帧率 · 信道影响扫描                    │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 关键技术参数（config/init_params.m）

| 参数 | 值 | 说明 |
|---|---|---|
| 调制方式 | QPSK (M=4) | 每符号 2 bit |
| 符号率 Rs | 250 kSps | |
| 每符号采样 L | 4 | |
| 采样率 fs | 1 MHz | fs = L×Rs，Pluto USB 稳定区间 |
| 滚降因子 β | 0.35 | RRC 成形 |
| 前导长度 | 32 符号 | 帧检测 + 频偏估计 |
| Payload 长度 | 256 符号 | 每帧数据 |
| 载波频率 | 2.4 GHz | ISM 频段 |

### 2.3 链路预算（本设计的物理可行性依据）

| 项 | 数值 | 说明 |
|---|---|---|
| 原始数据率 | 500 kbps | 250kSps × 2bit |
| 帧开销 | 32/288 ≈ 11% | 前导占比 |
| 有效数据率 | ≈ 445 kbps | 扣除前导 |
| 文字消息 | ≪ 1 kbps | 远低于容量，实时 |
| 遥测帧(≤100B@50Hz) | ≤ 40 kbps | 富余 |
| 320×240 灰度图像 | ≈ 1.1 s/帧 | 渐进重建（≈伪视频） |
| 640×480 灰度 | ≈ 4.4 s/帧 | 慢 |
| 视频 176×144@5fps | ≈ 1.0 Mbps | **超出容量，不可行** |

> **结论**：实时视频超出 Pluto-USB 链路容量；采用"图像渐进传输"作为演示高光，视觉近似慢速视频。

## 3. 帧结构设计（L4，本工程核心设计之一）

### 3.1 帧格式

```
| 前导 Preamble | 帧头 Header | Payload 数据 |
| 32 符号        | 8 符号       | 248 符号     |
| 64 bit         | 16 bit       | 496 bit      |
```

帧头字段（16 bit）：
- **帧类型**（2 bit）：00=文字, 01=遥测, 10=图像, 11=保留
- **帧长度**（6 bit）：payload 符号数（支持变长）
- **帧序号**（8 bit）：0~255 循环，用于丢帧统计

### 3.2 前导序列设计（报告理论深度点①）

前导需同时服务**帧检测**与**频偏估计**两个目标，序列选择有讲究：

**候选方案对比**：
| 方案 | 帧检测 | 频偏估计 | 说明 |
|---|---|---|---|
| 全 1 序列（全发同一个符号） | 相关峰宽、定时模糊 | 不能估频偏 | 差 |
| 随机 QPSK 序列 | 相关峰尖锐 | 可估（相位差法） | 好 |
| **交替 ±1 序列**（如 1,-1,1,-1,...） | 峰尖锐 | 相位差法有 2 倍符号率模糊 | 需规避 |
| **CAZAC/Zadoff-Chu 类序列** | 理想自相关 | 优秀 | 实现稍复杂 |

**本设计选择**：采用**已知伪随机 QPSK 序列**（固定种子生成，收发双方预置）。理由：
1. 伪随机序列自相关尖锐 → 帧检测峰值清晰（随机性越强，自相关旁瓣越低）
2. 频偏估计采用**前导分段相关相位差法**（见 §4.3），对任意已知序列适用
3. 实现简单，教学清晰（只需存一份已知序列）

> 这一节为报告"帧结构设计"章节提供对比论证，体现设计不是拍脑袋而是权衡。

## 4. 接收机同步算法链（L2，报告理论深度核心）

真实空口接收机比仿真多两大问题，本工程核心工作即在此：

### 4.1 问题描述
```
发送:   x(t) = Σ a[k]·p(t - kT)              (理想)
接收:   r(t) = e^{j2πΔf·t} · x(t - τ) + n(t)
                     ↑ 频偏(晶振失配)   ↑ 定时延迟(未知帧起点)
```
- **频偏 Δf**：两块 Pluto 晶振不同源时可达数百 Hz~kHz 量级（单板同源≈0）
- **定时延迟 τ**：接收端完全不知道波形从哪开始

### 4.2 帧检测：滑动相关（对应统计信号处理 = 匹配滤波/假设检验）

接收端用本地已知前导序列对接收波形做**滑动相关**：
```
C[n] = | Σ_m r[n + m] · p*[m] |        (滑动相关)
```
- 无帧时：C[n] ≈ 噪声（低）
- 帧到达：C[n] 出现**尖锐峰值** → 峰值位置 = 帧起点估计
- 门限检测：C[n] > λ·噪声功率 → 判定"有帧"（= 二元假设检验中的似然比思想）

**报告衔接**：帧检测本质是一个 **H0(无信号) vs H1(有信号)** 的检测问题，滑动相关器是最佳匹配滤波器。可将此节与统计信号处理（Bayes/ML 检测）衔接展开。

### 4.3 载波频偏估计：前导分段相位差法（报告理论深度点②）

对前导做**两段相同序列**的相关，利用相位差估计频偏：

设前导被分为两段（或利用同一已知序列），接收到的两段相关输出相位差为：
```
Δθ = 2π·Δf·T_sep        (T_sep = 两段起点时间间隔)
⇒  Δf̂ = Δθ / (2π·T_sep)
```
**推导要点**（报告素材）：
- 相关运算消除调制影响，留下纯频偏旋转
- 估计范围受限：|Δθ| < π → |Δf̂| < 1/(2·T_sep)；T_sep 小则范围大、精度低；需折中或用多级估计

### 4.4 频偏补偿与定时同步
- 补偿：`r_comp[t] = r[t] · e^{-j2π·Δf̂·t}`（复数乘法去旋转）
- 定时：利用帧检测峰 + 已知峰值偏移（复用 rx_baseband 的 length(rrc) 结论）定位符号抽样点

### 4.5 同步算法验证策略（单板约束下的方案）

| 层 | 验证内容 | 方法 |
|---|---|---|
| L2 仿真 | 算法正确性 | 注入已知频偏(0~500Hz) → 估计 → 补偿 → BER 恢复 |
| L3 单板 | 无频偏退化场景 | 真实空口频偏≈0，验证算法不误伤正常链路 |
| L4 双板 | 真实异源频偏 ★ | 借到第二块板后补做，作为报告加分实验 |

## 6. 测量与实验设计（L1，报告数据来源）

### 6.1 指标定义
- **BER**：错比特/总比特（与理论 `Q(√(2·Eb/N0))` 对比）
- **EVM**：误差矢量幅度（星座发散程度量化）
- **帧成功率 / 丢帧率**：帧号连续性统计

### 6.2 实验矩阵（报告数据章节骨架）

| 实验 | 变量 | 测量 | 报告价值 |
|---|---|---|---|
| E1 仿真 BER 扫描 | Eb/N0 0~10dB | BER vs 理论 | 算法正确性 |
| E2 频偏估计算法验证 | 注入 0~500Hz | 估计误差 | 同步算法章节数据 |
| E3 单板空口收发 | 固定参数 | 星座图/BER | 硬件链路可用性 |
| E4 增益扫描 | TxGain -30~-10dB | BER/EVM | 发射功率影响 |
| E5 距离/遮挡 | 0.3m~5m / 手遮挡 | BER/丢帧 | **信道影响演示** |
| E6 图像渐进传输 | 正常 vs 恶化 | 重建图像对比 | 现场演示 + 信道直观 |

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 第二块板借不到 | 无法实测真实频偏 | 仿真注入验证算法（主路径已覆盖）；双板作加分项 |
| 空口环境干扰(2.4GHz拥挤) | BER 异常 | 选信道干净时段/频点；用遮挡实验反证干扰 |
| MATLAB 处理延迟 | 帧率低 | 接受 10~50fps 准实时；定位为"准实时帧通信" |
| USB 丢帧 | 帧号跳变 | 帧号统计暴露；必要时降采样率 |
