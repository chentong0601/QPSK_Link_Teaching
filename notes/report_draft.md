# 基于 ADALM-Pluto 的低空无人机遥测 QPSK 链路设计与实现

**课程项目报告（初稿）**

---

## 摘要

本项目基于软件无线电平台 ADALM-Pluto（PlutoSDR），设计并实现了一条完整的 QPSK 数字通信链路，用于低空无人机遥测数据的无线传输。系统覆盖"内容编码 → 组帧 → QPSK 调制 → 脉冲成形 → 真实空口发射 → 帧同步 → 载波频偏补偿 → 解调 → 内容还原"全流程，支持文字消息、结构化遥测数据、灰度图像三类内容的传输。

**关键工作与结果**：
1. 设计了含前导序列与帧头的帧结构，实现接收端**帧检测**（滑动相关）与**载波频偏估计**（前导辅助相位差法）。
2. 在真实空口（2.4 GHz，两根天线）实现了文字消息的可靠传输，实测频偏估计 -112.6 Hz，公共相位偏移 -48.2°，消息完整还原。
3. 发现并解决了空口解调的关键问题——**QPSK 4 重相位模糊导致的公共相位偏移**（仿真中不暴露，真实空口必现），这是本项目最具价值的技术发现。
4. 仿真验证了图像多帧传输（32×32 灰度，17 帧），像素错误率 0%。
5. 完成硬件实测：接收增益扫描（接收功率随增益单调递增，跨越 3 个数量级）与同步稳定性测试（频偏估计 **-82.2 ± 4.5 Hz**，标准差约 5%），验证同步算法稳定可靠。

## 1. 引言

### 1.1 背景
低空无人机（UAV）的遥控、遥测与图传依赖可靠的数字无线链路。软件无线电（SDR）以"尽早数字化 + 软件处理"的架构，成为通信系统教学与研究的理想平台。ADALM-Pluto 基于 AD9363 射频收发器与 Zynq FPGA，支持 325 MHz–3.8 GHz 收发，是高校 SDR 教学的常用硬件。

### 1.2 项目目标
1. **功能**：实现真实空口可用的 QPSK 数据链路，支持文字/遥测/图像三类内容。
2. **理论**：深入理解数字接收机的核心——**同步问题**（帧同步与载波同步）。
3. **交付**：可运行系统 + 实测数据 + 现场演示。

### 1.3 相关工作
调研发现 GitHub 上同类课程设计项目 [ljd1996/pluto_design]（MATLAB + PlutoSDR）实现了 BPSK 链路的完整同步（Gardner 定时恢复、频偏同步、相位同步、CRC32）。本项目与之的**差异与增量**：
- 调制方式：本项目采用 **QPSK**（对比 BPSK，频谱效率更高，且引入 4 重相位模糊这一额外问题）
- 内容源：支持**多类内容**（文字/遥测/图像），而非单一文字
- 同步策略：在单板同源场景下采用**简化同步链**，并系统分析了空口与仿真的差异

## 2. 系统设计

### 2.1 五层架构

| 层 | 功能 |
|---|---|
| L5 应用层 | 内容源（文字/遥测/图像）编码为字节流 |
| L4 链路层 | 组帧：前导(32) + 帧头(16) + payload(248) 符号 |
| L3 物理层 TX | QPSK 调制 → 上采样 → RRC 成形 → 归一化 |
| L2 物理层 RX | 匹配滤波 → 帧检测 → 频偏补偿 → 相位校正 → 判决 |
| L1 测量层 | BER / 像素错误率 / 帧成功率 |

### 2.2 关键参数

| 参数 | 值 |
|---|---|
| 调制 | QPSK (M=4, 2 bit/符号) |
| 符号率 Rs | 250 kSps |
| 每符号采样 L | 4 |
| 采样率 fs | 1 MHz |
| 滚降因子 β | 0.35 |
| 载波频率 | 2.4 GHz |
| 帧长 | 296 符号 (前导32 + 帧头16 + payload248) |
| 有效数据率 | ≈ 445 kbps |

### 2.3 帧结构设计

```
| 前导 Preamble (32符号) | 帧头 Header (16符号=32bit) | payload (≤248符号=62字节) |
```

**帧头 32 bit**：类型(2) + payload字节数(8) + 帧号(8) + 校验(8) + 保留(6)

**前导序列选择论证**（报告理论点①）：前导需同时服务"帧检测"与"频偏估计"。对比方案：
- 全 1 序列：相关峰平坦 → 定时模糊，不可用
- 交替 ±1 序列：相位差法有 2 倍符号率模糊
- **伪随机 QPSK 序列（本项目选用）**：自相关尖锐 → 帧检测峰清晰；对任意已知序列可用相位差法估频偏

## 3. 接收机同步算法

### 3.1 帧检测（滑动相关）
接收端用本地已知前导波形对接收波形做滑动相关：
```
C[n] = | Σ_m r[n+m] · p*[m] |
```
帧到达时出现尖锐峰值，峰值位置即帧起点。**理论衔接**：滑动相关器即匹配滤波器，帧检测本质是 H0(无信号) vs H1(有信号) 的二元假设检验（对应统计信号处理）。

### 3.2 载波频偏估计（前导辅助相位差法，报告理论点②）
去调制后，接收前导符号 `d(k) = rx(k)·conj(preamble(k))` 仅剩频偏旋转：
```
d(k) ≈ A·exp(j(2πΔf·k·Ts + θ0)) + n
```
取前导首尾两段做相干平均（降噪），相位差估计频偏：
```
Δθ = angle(z2 · conj(z1)),  Δf̂ = Δθ / (2π·T_sep)
```
**估计范围**：|Δf̂| < Rs/(2·centerGap)，本项目 p=32, Nseg=8 → 范围 ±5208 Hz，覆盖需求。
**算法演进**（实测经验）：两段平均法 → 相邻符号差法（失败：300Hz 在 250kSps 下相邻相位差仅 0.0075 rad，淹没于噪声）→ **首尾分段法**（最佳）。

### 3.3 公共相位校正（本项目关键发现）
QPSK 存在 **4 重相位模糊**（0/90/180/270° 不可区分）。频偏补偿后仍残留**常数相位偏移**（来自 LO 初始相位、信道相位）：
```
ph0 = angle(mean(rxComp(1:P) · conj(preamble)))
rxCorrected = rxComp · exp(-j·ph0)
```
**这是空口相对仿真的关键差异**：仿真中 `pskmod` 从相位 0 开始，不暴露此问题；真实空口初始相位随机（实测 -48.2°），不校正则判决全错。

## 4. 实验结果

### 4.1 仿真验证（W2）
注入 300 Hz 频偏、Eb/N0=12 dB：
- 帧起点估计：1（正确）
- 频偏估计：310.5 Hz（误差 3.5%）
- 解调结果：**"HELLO QPSK!" 完整还原**

频偏扫描（0/50/100/200/300/500 Hz）：各点均正确估出。

### 4.2 真实空口验证（W3）
**配置**：2.4 GHz，TX 增益 -20 dB，RX 增益 30 dB，两根短天线。
**实测结果**：
| 指标 | 值 |
|---|---|
| 帧起点 | 38460 |
| 频偏估计 | -112.6 Hz |
| 公共相位偏移 | -48.2° |
| 帧头解析 | type=0, nBytes=11, crcOK=1 ✓ |
| 解调消息 | **"HELLO QPSK!" ✓** |

**调试过程**（体现工程能力）：初版解出乱码（帧头 type=2/nBytes=173）。通过保存接收数据离线分析，逐步排除：信号强度正常（相关峰28.5 vs 噪声0.8）、定时正确（d=0 最优）、符号判对率 100%（归一化后）→ 最终定位为**缺少公共相位校正**，修复后成功。

### 4.3 多内容源验证（W4）
| 内容 | 结果 |
|---|---|
| 文字 | 完整还原 [PASS] |
| 遥测帧 | 高度/速度/姿态/电量/GPS/模式 全部正确 [PASS] |
| 图像 (32×32, 17帧) | 像素错误率 0.00% [PASS] |

### 4.4 硬件实测数据（增益扫描与稳定性）

**实验 E4：接收增益扫描**（TxGain=-20 dB，天线距离约 15~20 cm，每档 5 次）

| RxGain (dB) | 解调成功率 | 频偏估计 (Hz) | 接收功率 |
|---|---|---|---|
| 20 | 60% | -84.8 | 2.24×10⁻⁴ |
| 25 | 100% | -80.7 | 2.25×10⁻⁴ |
| 30 | 100% | -86.1 | 8.17×10⁻⁴ |
| 35 | 40% | -84.1 | 3.91×10⁻³ |
| 40 | 80% | -82.8 | 1.60×10⁻² |
| 45 | 100% | -79.3 | 5.04×10⁻² |
| 50 | 100% | -89.5 | 1.70×10⁻¹ |

**分析**：
1. **接收功率随增益单调递增**（2.24×10⁻⁴ → 1.70×10⁻¹，跨越约 3 个数量级），验证接收链路增益控制正常。
2. **解调成功率非单调**（如 35 dB 时 40%，45 dB 时 100%）。这是**真实空口的典型特征**：每档仅 5 次采样，受环境噪声、反射、采样随机性影响，成功率存在统计波动。说明真实系统需要**多次重传/前向纠错**来保证可靠性。
3. **频偏估计稳定在 -80~-90 Hz**，与增益无关，说明该频偏是**真实的系统频偏**（见下）。

**实验 E5：同步算法稳定性**（RxGain=40 dB，重复 10 次）
- 成功率：9/10
- 频偏估计均值：**-82.2 Hz**，标准差：**4.5 Hz**

**关键发现**：频偏估计的标准差仅 4.5 Hz（约 5%），说明：
1. 同步算法**稳定可靠**，估计结果可重复；
2. 单板存在约 **-82 Hz 的真实固定频偏**（非随机误差）——虽然收发共用同一 Pluto，但 TX/RX 信号路径的时延差异或本振相位差会引入固定频偏。这一发现为后续双板实验（异源晶振，频偏更大）提供了基准。

## 5. 讨论

### 5.1 空口 vs 仿真的差异（核心洞察）
本项目最重要的发现是：**真实空口比仿真多出"公共相位校正"这一必需步骤**。原因是：
1. 仿真 `pskmod` 从相位 0 开始，星座天然对齐
2. 真实 Pluto 的 LO 有随机初始相位，且收发切换引入相位跳变
3. 不校正 → QPSK 判决整体旋转 → 全错

### 5.2 频偏估计精度分析
单板同源晶振下真实频偏≈0，但估出 -112 Hz，说明**低信噪比下相位估计方差较大**（接收符号幅度仅 0.082）。改进方向：增加前导长度、或采用多级估计（参考项目的粗+细分级方案）。

### 5.3 局限性
- 视频传输超出链路容量（176×144@5fps 需 1.0 Mbps > 445 kbps 有效容量），故采用图像渐进传输
- 第二块 Pluto 暂缺，真实异源频偏实验待补（仿真已覆盖算法验证）

---

## 6. 结论与展望

本项目完成了从纯仿真到真实空口的完整 QPSK 通信链路，支持文字、遥测、图像三类内容的传输，并在真实硬件上验证了同步算法的有效性。核心量化成果：

1. **真实空口闭环**：2.4 GHz 空口完整还原文字消息，帧同步与频偏补偿工作正常；
2. **同步算法稳定**：频偏估计 -82.2 ± 4.5 Hz（标准差 5%），算法可重复；
3. **多内容传输**：图像多帧传输像素错误率 0%；
4. **关键发现**：识别并解决了**空口解调的公共相位问题**（QPSK 4 重相位模糊），这是仿真中不暴露、真实系统必现的关键差异，深化了对"仿真与真实系统差异"的理解。

**展望**：
1. 引入 Gardner 定时恢复，提升定时精度
2. 双板实验，验证真实异源频偏下的同步性能
3. 增加 CRC 校验与自动重传，提升可靠性
4. 尝试更高阶调制（16QAM）或 OFDM
