## 1. 解决的问题

**症状**（`notes/exp_baseline_metrics.md` 记录）：现有接收机在满载荷 62 字节下，
12 dB 只有 35% 解帧成功率，且 BER 存在明显误码平台。

**根因**：频偏估计器的残余误差在**一个帧内累积成线性相位斜坡**。
实测证据（8 dB，按帧内位置分段）：

| 符号区间 | 1–37 | 112–148 | 223–259 | 260–296 |
|---|---|---|---|---|
| BER | 0.0000 | 0.0597 | 0.3170 | **0.3857** |

若**已知真实频偏**（不做帧内补偿），则**全帧 BER = 0.0000**。
⇒ 误码完全来自估计器残余，而非噪声。

**机理**：估计器标准差 84 Hz @12 dB（真频偏 0）⇒ 帧内相位漂移 **35.9°**，
逼近 QPSK 的 45° 判决边界。

---

## 2. 实现：`sync/phase_track.m`

一阶判决导向锁相环，**用已知前导定初相**（消解 4 重相位模糊 → 防跳周）：

```
theta = angle(mean(rxSym(1:p) .* conj(preambleSym)))    % 前导定初相
for k = 1:Nsym
    y = rxSym(k) * exp(-1j*theta)          % 相位去旋转
    s = decision(y)                        % 最近星座点判决
    e = Im{ y * conj(s) }                  % 相位误差检测 (≈ sin(相位误差))
    theta = theta + mu * e                 % 一阶环路更新
end
```

**为什么用 PLL 而不是更简单的方案**（`exp_w7_solution_study.md` 的结论）：

| 候选方案 | 结果 |
|---|---|
| 前导改重复结构 + 多段平均 | ❌ σ_f 反而恶化 7.6%（间隔缩小损失 > 多段平均收益） |
| 估计器换 ML | ❌ 仅改善 7%（已到极限） |
| 加长前导 32→64 | ⚠️ 有效（95%）但花 9.8% 带宽 |
| **批量判决导向精估** | ❌ **彻底崩溃**（帧尾判决出错 → 去调制变噪声 → 估计误差 3 万 Hz） |
| **DD-PLL** | ✅ **12 dB 35% → 100%，零带宽代价** |

**关键区别**：PLL 用**局部**判决逐步跟踪，不要求全局判决正确；
批量 DD 精估要求初始判决基本正确——而本场景恰好破坏了这个前提。

## 3. 集成方式

`receiver/rx_frame.m` 第 6 步（判决）：

```matlab
usePll = true;
if isfield(params,'PhaseTrack'), usePll = logical(params.PhaseTrack); end
if usePll
    mu = 0.10;
    if isfield(params,'PllMu') && ~isempty(params.PllMu), mu = params.PllMu; end
    [symIdxAll, thetaHist, rxTracked] = phase_track(rxSymComp, preambleSymShort, M, mu);
    diag.thetaHist = thetaHist;   diag.rxTracked = rxTracked;   diag.pllMu = mu;
else
    ... % 原路径（仅常数相位校正），用于对照实验
end
```

`config/init_params.m` 新增：
```matlab
params.PhaseTrack = true;    % 是否启用 DD-PLL（false 可作对照）
params.PllMu      = 0.10;    % 环路增益
```

**向后兼容**：`params.PhaseTrack = false` 即回到 W6 行为，便于做 A/B 对照；
`diag` 新增 `thetaHist` / `rxTracked` / `pllMu`，不删除任何原有字段。

| Eb/N0 | W6 无相位跟踪 | **W7 有 DD-PLL** |
|---|---|---|
| 4 dB | 0.0% | 0.0% |
| 6 dB | 5.0% | 35.0% |
| 8 dB | 25.0% | **90.0%** |

| 16 dB | 80.0% | **100.0%** |

**★ W7 在 10 dB 达到 100%，而 W6 在 16 dB 也只有 80% —— 等效增益约 6 dB。**

### 4.2 BER（理想切分，逐比特，200 次/点）

| Eb/N0 | W6 | **W7** | 理论 QPSK |
|---|---|---|---|
| 4 dB | 1.951e-1 | 1.860e-2 | 1.250e-2 |
| 6 dB | 1.416e-1 | 4.291e-3 | 2.388e-3 |
| **8 dB** | 9.809e-2 | **1.605e-4** | **1.909e-4** |
| 10 dB | 6.378e-2 | 0（<8.4e-6） | 3.872e-6 |
| 12 dB | 3.742e-2 | 0 | 9.006e-9 |
| 16 dB | 7.652e-3 | 0 | 2.267e-19 |

**★ 8 dB 时 W7 的 BER = 1.605e-4，与理论 1.909e-4 高度吻合。**

> **核心结论**：**W7 使接收机从"存在误码平台"恢复到"贴合理论极限"。**
> 这是本模块最有说服力的一句结论，建议作为报告该章的标题句。

> ⚠️ **测量分辨率说明**：200 次 × 592 bit = 118400 bit，
> 故 BER 低于 `1/118400 = 8.4e-6` 记为 0（"低于分辨率"而非"绝对无误码"）。
> 图中标注在 1e-4 处仅为可读性。

## 5. 设计决策与踩坑记录

| # | 事项 | 说明 |
|---|---|---|
| 1 | **环路增益选择 μ=0.10** | 实验对比 μ=0.02/0.05/0.10/0.20：μ≥0.05 在 ≥10 dB 均达 100%；**μ=0.10 在 8 dB 时最好（90%，其余为 75–85%）**，故选定 |
| 2 | **初相由前导给出** | 不依赖调用者是否已做常数相位校正 —— `phase_track` 内部自行估计，接口更鲁棒（已校正时结果≈0） |
| 3 | **判决函数用最近星座点** | `min(abs(y-ref))`，与接收链其余部分一致，避免引入第二套判决口径 |
| 4 | **相位误差检测用 `Im{y·conj(ŝ)}`** | 对 QPSK 等价于 sin(相位误差)，小误差下近似线性，适合一阶环 |
| 5 | **保留 `PhaseTrack=false` 路径** | 便于 A/B 对照实验（`main_w7_compare.m` 直接使用），也是回归基线 |
| 6 | 8 dB 时 PLL **反超**"已知真实频偏" | 因 PLL 把相位参考从 32 符号前导扩展到整帧 296 符号，低 SNR 下积累更长；"理想"方案仍只用了前导 |
